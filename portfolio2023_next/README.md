# 류대현 포트폴리오 2023-2024

2023년 제작했던, 제 소개를 위한 [프로필 포트폴리오](https://ryudh.com)입니다.

실무에서 다음의 환경에서 작업한 경험을 바탕으로,
부족한 부분을 보완하고 지금의 제 역량을 기준으로한 코드를 보여드리기 위해
리팩토링을 진행하고 있습니다.
